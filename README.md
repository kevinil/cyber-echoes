# 回声 · 吉他和弦谱

放在 iPad 谱架上的看谱器。歌词自动滚动,字号随时调,和弦落在对应的字上方,整页安静、不打扰。

纯静态网页(PWA),不需要开发者账号,不需要服务器,免费托管就能在 iPad 上全屏使用,装到主屏幕后断网也能看。

## 现在能做什么

- **曲库**:新建、编辑、删除,按最近修改排序,显示当前调号(转调后如 `D +2`)。
- **看谱**:歌词自动滚动,速度可调;字号 0.7×–1.8× 随时缩放;短到一屏放得下的谱会显示「无需滚动」。
- **暂停**:滚动的过程中点一下谱面就停,再点播放继续;控制条会自动隐去,点一下回来。
- **和弦**:用 `[C]` 写在字前,和弦就落在那个字的上方;长和弦会自动让出宽度,不重叠。
- **转调**:整首升/降半音,原调跟着变,点调号可一键还原。
- **常亮**:看谱时自动请求屏幕常亮(iPadOS 16.4+ 支持)。
- **翻页踏板**:蓝牙踏板当作键盘用 —— 空格开始/暂停,PageUp/PageDown / 方向键翻动。
- **离线**:添加到主屏幕后,Service Worker 会缓存全部文件。
- **备份**:曲库导出/导入 JSON,数据只存在本机。

## 记谱格式

用业界通用的 ChordPro 写法,一个方括号就是一和弦,位置由它在歌词里的位置决定:

```
# 主歌
[C]长亭外 [G]古道边
[F]芳草碧连 [C]天
[Am]晚风拂柳 [Em]笛声残
[Dm]夕阳山 [G]外山
```

规则很少:

| 写法 | 效果 |
|---|---|
| `[C]字` | 和弦 C 显示在「字」的正上方 |
| `[C#m7]` `[G/B]` `[Cmaj7]` | 任意和弦名都行,转调时会跟着变 |
| `[前奏]` `[间奏]` `[N.C.]` | 方括号里可以写任意文字;不是和弦的标记不会被转调 |
| `# 副歌` | 以 `#` 开头的一行是小标题 |
| 空行 | 段落之间留白 |
| `[G]  [D]  [Em]  [C]` | 纯和弦行:方括号之间用空格控制间距 |

编辑页上方有一排常用和弦,点一下就会插到光标处;编辑器下方是实时预览。

和弦与歌词的位置精确到「字」:方括号放在哪个字前面,和弦就压在哪个字上。写中文不需要空格;写英文时和弦会落在单词的开头。

## 在 iPad 上安装

1. 把整个文件夹部署到任意静态托管(见下),拿到 HTTPS 网址。
2. 用 iPad 的 **Safari** 打开这个网址。
3. 点工具栏的「分享」→「添加到主屏幕」。
4. 从主屏幕打开,就是全屏、无地址栏的 App。

> 先装到主屏幕,再开始录自己的谱。iOS 上 Safari 和主屏幕 App 的本地存储可能是分开的,先在浏览器里录谱再安装,谱子不一定会跟过去。

> 必须用 Safari 添加到主屏幕。Chrome/Edge 在 iPad 上没有这个入口。

## 部署(免费,不需要开发者账号)

任选一种,推荐第一个:

### Cloudflare Pages(拖拽上传)

1. 打开 <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
2. 项目名随意,把 **本项目文件夹里的所有文件** 拖进去(`index.html` 必须在根目录)。
3. Deploy,得到 `https://<项目名>.pages.dev`。

### Netlify Drop

打开 <https://app.netlify.com/drop>,把整个文件夹拖进去,立刻得到网址。

### GitHub Pages

新建仓库,上传全部文件,Settings → Pages → 选择分支根目录。国内访问 GitHub Pages 可能不稳定,优先用上面两个。

## 数据和备份

- 曲库保存在浏览器的 localStorage 里,**只在这台设备上**。
- 换设备、清理浏览器数据、卸载主屏幕图标前,先在曲库底部点「导出备份」。
- 在 iPad 上点「导出备份」会打开系统分享面板,可以直接存到「文件」或 AirDrop;电脑上会下载一个 JSON 文件。
- 在新设备上「导入备份」即可恢复。
- iOS 在存储紧张时可能清理网站数据,定期导出是唯一的保险。

## 文件结构

```
index.html              页面骨架(曲库 / 看谱 / 编辑三个视图)
app.css                 全部样式(Hallmark 设计系统,含 tokens)
tokens.css, base.css    设计令牌与基础样式
app.js                  渲染、路由、滚动、转调、存储
sw.js                   Service Worker(离线缓存)
manifest.webmanifest    PWA 清单
icons/                  主屏幕图标
.hallmark/              设计过程记录(不参与运行)
```

## 开发备注

- 改动后若已部署,把 `sw.js` 里的 `echo-shell-v1` 改成 `v2`、`v3`……再部署,否则浏览器可能继续用旧缓存。
- 和弦渲染在 `app.js` 的 `renderLine` / `fitChords`;转调在 `transposeChord`。
- 想加功能(搜索、分组、自动翻页、深色模式),在现有一套视图上扩展即可。
